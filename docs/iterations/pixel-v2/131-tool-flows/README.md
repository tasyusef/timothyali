# The Toolbox tools as diagrams (PX-131, 0234)

Each tool on `/toolbox/` is now one line: what goes in, an arrow, what Toolbox 1.2.5 wrote for it, with a count and the real files as a zip underneath. Before this, each was a miniature of the app's settings (PX-130's `demos-before-after-app.png`), which showed how to use the app rather than what it makes.

## Shots

Headless, motion off, the tool section of `/toolbox/` on the production preview.

- `flows-1440-dark.png`, `flows-1440-light.png`: the four diagrams, Lockup to Convert.
- `flows-390-dark.png`, `flows-390-light.png`: the same on a phone, what goes in above what comes out.
- `rejected-sample-1440-dark.png`: the interim interactive Lockup sample (filters, file sheet, preview). Timothy found it as hard to follow as the demo it replaced, which led to the diagram.
- `review/`: every shot `tools/review/toolbox-demo.mjs` takes (1440, 390 and 320, both themes, each tool) and its `report.json`.
