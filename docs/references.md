## The fork these references expose

3D on a portfolio takes one of three shapes. Timothy needs to pick before the concept is briefed (Q15):
1. **World**: an environment you move through (Bruno Simon, Samsy). Highest cost, highest clone risk, worst for a skimming founder.
2. **Object**: one thing with weight on the first screen (Oryzo, Hubtown). Cheapest to do well, most compatible with 0012, easiest to make unique because the object can be anything.
3. **Material**: depth as light, texture, and physics applied to the type and layout itself, with no scene at all (closer to Mat Voyce, Obys). Keeps the grid as the star. Hardest to make feel "not flat" but most tim-shaped if the wordmark is strong.

Claude's lean: Object or Material, not World.
