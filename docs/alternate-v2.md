## The grid

Every font is a bitmap design with a known number of cells per em, so a size is `cells/em × cell`. The table lives at the top of `src/app.css` and is repeated in `docs/design-system.md`. If you change a font-size, keep it on that table or the glyph pixels blur. Spacing is in 8px units. Black and white with a theme toggle (`html[data-theme]`, tokens `--paper`/`--fg`), yellow only as `--accent` on cursors, active nav and action blocks (CTAs, the hero scroll hint); there are no rules or borders — bands are separated by space, filled yellow blocks (`.cta`, `.cta-row`, active nav) and texture. Secondary text uses `.dim` (55% opacity). Cards use `.card` (pixel-pattern surface). A band with a programmatic background is `.band` + `.band-bg`. Turn on **Grid** in the footer to see the 8px/64px overlay.

| face | role | cells/em | sizes used |
|---|---|---|---|
| Jacquard 24 | wordmark, emphasis words | 43 | 43, 86, 129, 172, 258, 344 |
| Jersey 25 | uppercase display | 41 | 41, 82 |
| Jersey 15 | body copy, case-study lead | 27 | 27 (line 32), 54 (line 64) |
| Silkscreen | labels, navigation, buttons | 8 | 16 |
| Press Start 2P | readout, path, arrows | 8 | 16 (8 on mobile readout) |

## Files

- `src/app.css` — the cell table and seven `@import`s, nothing else.
- `src/lib/styles/primitives.css` — raw values: `--yellow --ink --white`, the spacing scale `--u --s1 --s2 --s3 --s4 --s6 --s8 --s12 --s16`, the cells `--cell-text --cell-image --cell-texture`, the face stacks `--face-*`, `--tick-cursor`, `--nudge`, and the five breakpoints as a comment.
- `src/lib/styles/tokens.css` — semantic tokens: `--paper --fg --accent --on-accent --dim --gutter --header-height`, `--surface-card` / `--surface-card-hover`, `--grid-fine` / `--grid-major`, `--z-band-bg --z-band --z-chrome --z-nav --z-grid --z-skip`, `--texture-fallback-opacity`, and the light-theme swap.
- `src/lib/styles/base.css` — element defaults, `.sr-only`, the one `@keyframes blink`.
- `src/lib/styles/type.css` — the type roles `.blackletter .display-xl .display .display-s .lead .body .lbl .mono .dim` and their responsive ladders. `.display-l` is gone (unused).
- `src/lib/styles/chrome.css` — sticky header, wordmark, path, status strip, global footer, and their phone rules.
- `src/lib/styles/layout.css` — `.site`, `section`, `.band` / `.band-bg`, the Grid overlay, `.inner-page`.
- `src/lib/styles/blocks.css` — the CSS half of the components: `.cursor`, `.cta` / `.cta-row` / `.cta-hint` / `.cta-quiet`, `.quiet-link`, `.plate`, `.index-row`, `.page-foot`, `.cards` / `.card`, `.rows` / `.row` / `.row-body`.
- `src/lib/tokens.ts` — the same primitives for JavaScript: `INK WHITE YELLOW`, `U CELL_TEXT CELL_IMAGE CELL_TEXTURE`, `TICK_SLOW TICK_FAST` (Ascii), `STEP_SLOW STEP STEP_FAST` (Decode).
- `src/routes/+layout.svelte` — font imports, top bar (wordmark, path + cursor in a `minmax(0,1fr)` column that clips long routes instead of pushing the nav, numbered nav), inverted readout strip with the live Mountain-time clock, footer with Motion and Grid toggles. Resolves the saved motion choice / OS preference on mount.
- `src/lib/motion.svelte.ts` — shared `motion`, `grid` and `theme` state.
- `src/app.html` — inline script that applies the stored theme before first paint (dark unless `tim-theme` is `light`).
- `src/lib/prng.ts` — seeded PRNG, value noise, fBm, Bayer 4×4 and 8×8 matrices.
- `src/lib/glyphs.ts` — 5×7 bitmap glyphs and the density ramp used by the ASCII renderer.
- `src/lib/knockout.ts` — text knockout for textures: measures text line boxes and returns a dithered falloff factor. Pass `avoid="<selector>"` (resolved inside the nearest `.band`) plus `pad`/`feather` in cells to `Band`/`Ascii`.
- `src/lib/components/Band.svelte` — a section with a full-bleed ASCII field behind it: renders `.band` + `.band-bg` + `Ascii`. Props `as class mode seed tick density avoid` plus children. Used by the Home hero (`sky`), the Home work/invitation rain (`as="div"`, `fall`) and Contact (`fall`).
- `src/lib/components/Ascii.svelte` — bitmap ASCII field, reached through `Band`; modes `noise | fall | scan | sparse | sky | bands` (`bands` unused since PX-07); props `mode cell px seed tick density avoid pad feather interactive reach`; origin snapped to the page grid; pointer heat with trails and click rings (listeners on the enclosing `.band`); redraws at ~30fps with sprite-cached glyphs, field cadence set by `tick`, off-screen bands paused. Note the `fall` field is a function of the canvas row count, so changing a band's height re-seeds its whole texture.

## Behaviour

Motion defaults to the OS preference and is remembered per browser. With motion off, or without JavaScript, every texture shows a static frame or a CSS checker, every word is fully printed, and nothing is hidden. All animation is discrete: ticks, steps, whole cells. There is no requestAnimationFrame loop.
